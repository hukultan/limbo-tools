# limbo-tools

Read/write tooling for the data files of **LIMBO** (Playdead, Steam appid 48000) —
the `.pkg` container and the A8L8 (16-bit luminance+alpha) sprite/atlas textures.

These are research tools for modding a game you own. **No game files, extracted
assets or decompiled code are included or generated by this repo.**

## Files

All scripts live in [`tools/`](tools).

| Tool | Purpose |
|------|---------|
| `tools/unpack_limbo.py` | Extract a `limbo_boot.pkg` / `limbo_runtime.pkg` into files. |
| `tools/repack_limbo.py` | Rebuild a `.pkg`, replacing named entries; identity-safe. |
| `tools/limbo_tex.py` | Inspect / decode / patch / round-trip sprite + atlas textures. |
| `tools/make_titlezero.py` | Example edit: zero the luma plane of a standalone sprite. |
| `tools/shot_diff.py` | Diff a sequence of screenshots (numpy/PIL) to confirm an edit. |

## Install

Python 3.10+. `tools/limbo_tex.py`, `tools/make_titlezero.py` (optional) and
`tools/shot_diff.py` need
[`numpy`](https://pypi.org/project/numpy/) and [`pillow`](https://pypi.org/project/pillow/):

```
pip install numpy pillow
```

`tools/unpack_limbo.py` and `tools/repack_limbo.py` are pure standard library.

## Container format (`*.pkg`)

```
u32 count
count x { u32 name_hash ; u32 entry_off ; u32 size }   # entry_off relative to table end
blobs at  4 + count*12 + entry_off
```

`name_hash` is the CRC32 of the entry's lowercase, `/`-separated path. Entries whose
name ends in `.d` are stored zlib-deflated; everything else is raw.

To get readable filenames you need the community filelists from
[Gibbed.Limbo](https://github.com/gibbed/Gibbed.Limbo)
(`bin/projects/LIMBO/files/limbo_boot.filelist` and `limbo_runtime.filelist`). They are
not bundled here. Unknown hashes land in `__UNKNOWN/<hash>.bin`.

## Usage

```
# unpack (boot + runtime)
python tools/unpack_limbo.py  limbo_boot.pkg     <filelist_dir>  out/boot
python tools/unpack_limbo.py  limbo_runtime.pkg  <filelist_dir>  out/runtime

# textures
python tools/limbo_tex.py inspect  out/boot/derived/pc/data/sprites/edges/metal_heavy.png
python tools/limbo_tex.py decode   FILE --w 512 --h 16 --out metal_heavy.png
python tools/limbo_tex.py patch    FILE --out NEW --in edited.png --w 512 --h 16
python tools/limbo_tex.py roundtrip FILE ...          # parse + re-emit, compare SHA

# example edit (same byte length keeps the .d deflate valid)
python tools/make_titlezero.py  out/boot/.../limbo\ title.png  title_zero.png

# repack: replace one entry, everything else copied verbatim
python tools/repack_limbo.py  limbo_boot.pkg  <filelist_dir>  new_boot.pkg \
    --entry "derived/pc/data/sprites/text/menu/limbo title.png.d" --in title_zero.png

# sanity: rebuilding with no --entry replacements is byte-identical to the input
python tools/repack_limbo.py --identity-test limbo_boot.pkg <filelist_dir>

# confirm an in-game change
python tools/shot_diff.py vanilla.png modded.png
```

Copy the rebuilt `new_boot.pkg` over the installed `limbo_boot.pkg` (back it up first)
and launch via Steam. Steam does not revert swapped pkgs.

## Texture format (A8L8)

Standalone sprites (`data/sprites/**/*.png`, `.png_a`, `.pngblur`) and atlases
(`data/texture/atlas/*.pngatlas`) share a wrapper:

```
u32 = 9 ; u32 = 2 ; u32 flags (1 sprite / 9 blur / 17 atlas) ; u32 (authoring cruft)
u8 pathLen ; ascii lowercase '/' path
u32 = 7 ; u16 ; u16 W ; u16 H ; u16 usedW ; u16 usedH ; u16 ; u16   # 18-byte header
pixels at path_end + 18, to EOF
```

Each texel is a little-endian `u16`; low byte = luma (**L drives on-screen
visibility**, `L=0` invisible), high byte = alpha (**effectively unused**).

Standalone sprites store a full mip chain and do **not** store W/H (count it from the
pixel size); atlases are 4096-wide sheets whose pixel data is a 6-level mip chain, with
virtual W/H in the header. Atlas path→rect tables are the shipped
`data/texture/atlas/*.txt` manifests.

Full write-up (formats, gotchas, verification): `universal-modder` field note
`knowledge/games/limbo/pngatlas-a8l8-format.md`.
