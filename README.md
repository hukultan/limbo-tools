# limbo-tools

Read/write tooling for the data files of **LIMBO** (Playdead, Steam appid 48000) —
the `.pkg` container and the A8L8 (16-bit luminance+alpha) sprite/atlas textures.

These are research tools for modding a game you own. **No game files, extracted
assets or decompiled code are included or generated by this repo.**

## Files

All scripts live in [`tools/`](tools).

| Tool | Purpose |
|------|---------|
| `tools/unpack_limbo.py` | Extract a `limbo_boot.pkg` / `limbo_runtime.pkg` into files. |
| `tools/repack_limbo.py` | Rebuild a `.pkg`, replacing named entries; identity-safe. |
| `tools/limbo_tex.py` | Inspect / extract / pack / patch / round-trip sprite + atlas textures. |
| `tools/limbo_workflow.py` | Bulk human-edit loop: dump every sprite + atlas member to PNGs, then rebuild only the ones you changed. |
| `tools/make_titlezero.py` | Example edit: zero the luma plane of a standalone sprite. |
| `tools/shot_diff.py` | Diff a sequence of screenshots (numpy/PIL) to confirm an edit. |

## Install

Python 3.10+. `tools/limbo_tex.py`, `tools/limbo_workflow.py`, `tools/make_titlezero.py`
(optional) and `tools/shot_diff.py` need
[`numpy`](https://pypi.org/project/numpy/) and [`pillow`](https://pypi.org/project/pillow/):

```
pip install numpy pillow
```

`tools/unpack_limbo.py` and `tools/repack_limbo.py` are pure standard library.

## Container format (`*.pkg`)

```
u32 count
count x { u32 name_hash ; u32 entry_off ; u32 size }   # entry_off relative to table end
blobs at  4 + count*12 + entry_off
```

`name_hash` is the CRC32 of the entry's lowercase, `/`-separated path. Entries whose
name ends in `.d` are stored zlib-deflated; everything else is raw.

To get readable filenames you need the community filelists from
[Gibbed.Limbo](https://github.com/gibbed/Gibbed.Limbo)
(`bin/projects/LIMBO/files/limbo_boot.filelist` and `limbo_runtime.filelist`). They are
not bundled here. Unknown hashes land in `__UNKNOWN/<hash>.bin`.

## Usage

```
# unpack (boot + runtime)
python tools/unpack_limbo.py  limbo_boot.pkg     <filelist_dir>  out/boot
python tools/unpack_limbo.py  limbo_runtime.pkg  <filelist_dir>  out/runtime

# textures
python tools/limbo_tex.py inspect  out/boot/derived/pc/data/sprites/edges/metal_heavy.png
python tools/limbo_tex.py extract  SPRITE.png --out metal_heavy.png          # dims from header
python tools/limbo_tex.py extract  ATLAS.pngatlas --rect 804,2345,215,206 --out head.png
python tools/limbo_tex.py pack     SPRITE.png --out NEW --in edited.png      # rebuild + mips
python tools/limbo_tex.py patch    SPRITE.png --out NEW --in edited.png      # same, in-place
python tools/limbo_tex.py patch    ATLAS.pngatlas --out NEW --in edited.png \
        --rect 804,2345,215,206 --mips                                       # edit all atlas mips
python tools/limbo_tex.py roundtrip FILE ...          # decode+re-encode pixels, check byte-identical

# bulk human-edit loop: dump every sprite + atlas member to PNGs at once,
# a human edits any of them, then pack rebuilds only what changed
python tools/limbo_workflow.py extract --boot out/boot --out assets
python tools/limbo_workflow.py pack --boot out/boot --assets assets ^
    --pkg-in limbo_boot.pkg --filelists <filelist_dir> --pkg-out new_boot.pkg

# example edit (same byte length keeps the .d deflate valid)
python tools/make_titlezero.py  out/boot/.../limbo\ title.png  title_zero.png

# repack: replace one entry, everything else copied verbatim
python tools/repack_limbo.py  limbo_boot.pkg  <filelist_dir>  new_boot.pkg \
    --entry "derived/pc/data/sprites/text/menu/limbo title.png.d" --in title_zero.png

# sanity: rebuilding with no --entry replacements is byte-identical to the input
python tools/repack_limbo.py --identity-test limbo_boot.pkg <filelist_dir>

# confirm an in-game change
python tools/shot_diff.py vanilla.png modded.png
```

`limbo_workflow.py extract` writes `assets/MANIFEST.json` recording, for each PNG,
its source texture and (for atlas members) the manifest rect, plus the PNG's
original SHA-256 — so `pack` rebuilds only the textures a human actually changed
and leaves every other pkg entry verbatim.

Copy the rebuilt `new_boot.pkg` over the installed `limbo_boot.pkg` (back it up first —
e.g. `um backup` from universal-modder) and launch via Steam. Steam does not revert
swapped pkgs. `repack_limbo.py` refuses to write over the input pkg or an existing
output file unless you pass `--force`.

## Texture format (A8L8)

Standalone sprites (`data/sprites/**/*.png`, `.png_a`, `.pngblur`) and atlases
(`data/texture/atlas/*.pngatlas`) share a wrapper:

```
u32 = 9 ; u32 = 2 ; u32 flags (1 sprite / 9 blur / 17 atlas) ; u32 (authoring cruft)
u8 pathLen ; ascii lowercase '/' path
u32 = 7 ; u16 ; u16 W ; u16 H ; u16 usedW ; u16 usedH ; u16 ; u16   # 18-byte header
pixels at path_end + 18, to EOF
```

Each texel is a little-endian `u16`; low byte = luma (**L drives on-screen
visibility**, `L=0` invisible), high byte = alpha (**effectively unused**).

The 18-byte internal header stores **W/H** for both sprites and atlases (e.g. the
menu title is `W=2048 H=1024 usedW=1280 usedH=720`), so `extract` needs no size
guessing. The pixel region is a **full mip chain** (level 0 first, each level a
half-size box average), so a standalone sprite's texel count is not `W*H` but
`W*H + W/2*H/2 + …` down to the level where a side reaches 1.

Mip levels are the original artist's data and, in the shipped files, are exactly
2×2 **floor** averages of the L and A bytes taken independently (verified
byte-exact on 140/140 standalone sprites). `pack` therefore regenerates them that
way when you edit level 0, and the rebuild is byte-identical when you don't.

Atlases are 4096-wide level-0 sheets whose pixel data is a 6-level mip chain
(`atlas_blur` 4096×4096, `atlas_norm` 4096×1024). Atlas path→rect tables are the
shipped `data/texture/atlas/*.txt` manifests; a rect is
`x y w h offX offY "path"` (TAB-separated). To repaint one member, keep its rect
and edit those texels — `patch --rect ... --mips` writes the edit into every mip
level so a member drawn small or through the blur pass doesn't sample stale art.

Full write-up (formats, gotchas, verification): `universal-modder` field note
`knowledge/games/limbo/pngatlas-a8l8-format.md`.

## Safety & scope

- **Only touches files you point it at.** No network access, no subprocesses, no
  `eval`, and no file deletion anywhere in these scripts.
- **`unpack_limbo.py` confines output to `<outdir>`;** a filelist entry that tries to
  escape it (absolute path or `..`) is refused, and such entries are counted as
  `skipped`.
- **`repack_limbo.py` will not overwrite the input pkg, and will not overwrite an
  existing output file without `--force`.** The identity rebuild proves an untouched
  repack is byte-identical.
- **Always back up** `limbo_boot.pkg` / `limbo_runtime.pkg` before copying a rebuilt
  one into the game.
- **No DRM / anti-cheat bypass.** LIMBO is a single-player game; the `.pkg` is a plain
  data container. Use these tools on a game you own.
